Setup Guide

Connect AppConsol to your App Store Connect account in 3 minutes. Your data never leaves your device.

~3 minutes
Before you start

You need an Apple Developer account with the Account Holder or Admin role. Sign in at appstoreconnect.apple.com before following this guide.

1

Generate an API Key

In App Store Connect, go to Users and Access → Integrations tab → App Store Connect API → Team Keys. Click the + button to generate a new key. Give it any name (e.g. 'AppConsol') and select the Admin access role.

Users and Access › Integrations › App Store Connect API › Team Keys › +
💡 Choose Admin role When creating the key, select 'Admin' as the access role. This is required to access sales and financial report data. Other roles (e.g. Developer, Marketing) won't have sufficient permissions.
2

Collect your credentials

You need four pieces of information. All are on two pages in App Store Connect:

① Issuer ID
On the same Integrations → App Store Connect API page. The Issuer ID is displayed at the very top of the page, with a Copy button next to it.
Users and Access › Integrations › App Store Connect API › Issuer ID (top of page)
② Key ID
In the Team Keys table, find the key you just created. The Key ID is the short alphanumeric string in the KEY ID column.
Team Keys table › KEY ID column
③ Private Key (.p8 file)
In the Team Keys table, click "Download API Key" next to your key. This downloads a .p8 file. Important: this file can only be downloaded once.
Team Keys table › Download API Key
④ Vendor Number
Go to Payments and Financial Reports (separate page). Your Vendor Number is shown in the top-left corner, right below your name.
Payments and Financial Reports › top-left › Vendor #
⚠️ The .p8 file can only be downloaded once. If you lose it, you'll need to revoke the current key and generate a new one from Team Keys.
3

Paste into AppConsol

Open AppConsol on your iPhone → Settings → API Setup. Paste your Issuer ID, Key ID, Private Key content, and Vendor Number into the corresponding fields.

📋 How to paste the .p8 file Open the .p8 file with any text editor (Notes, TextEdit, etc.), select all the content including the -----BEGIN/END PRIVATE KEY----- lines, copy it, and paste into the Private Key field in AppConsol.
🔒 Your data stays on your device AppConsol connects directly to Apple's API from your iPhone. No server, no middleman. Your private key is stored in iOS Keychain with hardware encryption.
✓

You're all set!

AppConsol will now fetch your sales data. Your first dashboard will be ready in seconds.
