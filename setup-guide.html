Setup Guide

Connect AppConsol to your App Store Connect account in 3 minutes. Your data never leaves your device.

~3 minutes
Before you start

You need an Apple Developer account with the Account Holder or Admin role. Sign in at appstoreconnect.apple.com before following this guide.

1

Generate your Individual API key

Click your name in the top-right corner → Edit Profile → scroll down to the Individual API Key section → click Generate Key.

Your Name › Edit Profile › Individual API Key › Generate Key
💡 Your account needs Admin role Individual API keys inherit your account's permissions. Admin or Account Holder role is required to access sales and financial data.
2

Collect your credentials

You need four pieces of information from three different pages. Here's where to find each one:

① Key ID
On your Edit Profile page, in the Individual API Key table. It's the alphanumeric string next to your key.
Edit Profile › Individual API Key › KEY ID column
② Private Key (.p8 file)
Same page — click "Download API Key" on the right side. This file can only be downloaded once.
Edit Profile › Individual API Key › Download API Key
③ Issuer ID
Navigate to Users and Access → Integrations tab → App Store Connect API. The Issuer ID is displayed at the top with a Copy button.
Users and Access › Integrations › App Store Connect API › Issuer ID
④ Vendor Number
Go to Payments and Financial Reports. Your Vendor Number is shown in the top-left corner, right below your name.
Payments and Financial Reports › top-left › Vendor #
⚠️ The .p8 file can only be downloaded once. If you lose it, you'll need to revoke the current key and generate a new one.
3

Paste into AppConsol

Open AppConsol on your iPhone → Settings → API Setup. Paste your Issuer ID, Key ID, Private Key content, and Vendor Number into the corresponding fields.

🔒 Your data stays on your device AppConsol connects directly to Apple's API from your iPhone. No server, no middleman. Your private key is stored in iOS Keychain with hardware encryption.
✓

You're all set!

AppConsol will now fetch your sales data. Your first dashboard will be ready in seconds.
